# Privacy checklist

Current prototype model: static pages only. No accounts, no forms, no analytics, no signatures and no intentional collection of health data.

## Current browser storage

- `mws-lang`: selected language.
- `mws-save`: local story progress.

Both are stored in the visitor's browser only. GitHub Pages and external links may still process standard technical data outside this project's control.

## Before adding data collection

1. Define the purpose and legal basis.
2. Minimize fields, especially health-related data.
3. Document retention and deletion.
4. Review processor terms and data-processing agreements.
5. Publish clear privacy terms before asking users to submit anything.
6. Re-run accessibility and security checks for any embedded tool.

Petition signing should happen on a vetted external platform only after legal/privacy review.
