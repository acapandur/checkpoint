Privacy

No personal sexual-health data belongs in this MVP.

The prototype is designed to be playable and readable without login, tracking forms or personal health input.

What the site does not collect

  • No names, e-mail addresses or accounts.
  • No personal sexual-health details.
  • No location input from players.
  • No petition signatures on this website.
  • No analytics in the MVP code.

How the game works

The game runs in the browser using fictional signal cards. Scores exist only in the current play session. The copy-result button uses the browser clipboard only if the player chooses it.

External links

If the campaign later links to an external petition platform, that platform will have its own privacy policy. The petition bridge should explain this before sending people away from the campaign site.
