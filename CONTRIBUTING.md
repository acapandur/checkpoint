# Contributing

This project is maintained by the Karta bez stigme project team.

Individual contributors are not publicly listed for privacy and safety reasons. Public commits, issues, releases and generated files should use neutral project identity rather than personal names, private emails, personal social handles or local machine paths.

## Public identity rules

- Use `Karta bez stigme tim`, `Project team` or `Neovisni projektni tim` for public attribution.
- Use placeholder contacts only until project-controlled inboxes exist: `contact@example.org`, `privacy@example.org`, `security@example.org`.
- Do not add personal author metadata, creator names, social handles, local paths, source maps or exported-file metadata that identifies an individual contributor.
- Do not imply an official organization, partner, medical authority or legal entity unless it has been formally approved.

## Git identity

For a public handoff repository, use a fresh repository with neutral identity:

```bash
git config user.name "Karta bez stigme tim"
git config user.email "dev@example.org"
```

Do not publish private development history. See `docs/public-handoff.md`.
